# Inventory Risk Analysis Tool

This project is a simple utility developed to analyze warehouse inventory data and identify supply chain risks.

Features
- Reads inventory data from a CSV file
- Detects products where stock levels fall below reorder thresholds
- Handles inconsistent or invalid data safely
- Outputs a clear list of items requiring restocking

 Technologies Used
- Python
- CSV file handling
- Git & GitHub for version control
- GitHub Copilot for assisted development
